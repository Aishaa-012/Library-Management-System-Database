# Library Management System (LMS-DB)

A relational database project designed to automate library operations, including book cataloguing, member registration, and loan transaction management.

## 🚀 Overview
This project addresses the challenges of manual record-keeping in libraries by providing a centralized, normalized relational database. It ensures data integrity, minimizes redundancy, and enables efficient retrieval of information regarding books, members, and circulation.

## 🛠 Tech Stack
- **Database**: MySQL
- **Modeling Tool**: MySQL Workbench

## 📁 Repository Structure
- `/sql`: Contains scripts for database schema, sample data, and complex query demonstrations.
- `/docs`: Contains the detailed project report.

## 💡 Key SQL Concepts Demonstrated
- **Normalization**: Schema designed up to 3NF.
- **Data Integrity**: Enforced via Primary Keys, Foreign Keys, and Cascading rules.
- **Complex Queries**: Joins, Aggregate functions, Subqueries, and Grouping.
